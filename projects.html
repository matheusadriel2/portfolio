kofin

Plataforma fintech educacional criada como parte de um projeto proposto pela FIAP.

Kofin é uma plataforma fintech que integra gestão financeira com foco em educação. O projeto envolve o desenvolvimento de uma API RESTful em Java, aplicando princípios de Programação Orientada a Objetos (POO) e arquitetura em camadas, integrada a um banco de dados Oracle. Inclui a criação de modelos lógico e relacional, bem como a elaboração de diagramas UML. Por fim, a interface gráfica foi projetada no Figma e desenvolvida utilizando Bootstrap 5, HTML, CSS e JavaScript.

Decoder

Encriptador e decodificador de mensagens

Aplicação web desenvolvida como parte do desafio do programa ONE da Oracle, em parceria com a Alura, que consiste em encriptar e desincriptar mensagens.

Desenvolvido utilizando HTML, CSS e JavaScript para praticar lógica de programação. O HTML estrutura a página, o CSS estiliza os elementos de forma atraente e responsiva, e o JavaScript adiciona interatividade. Primeiro projeto feito para desenvolver o raciocínio lógico e as habilidades no desenvolvimento web.
